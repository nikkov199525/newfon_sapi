# Newfon SAPI

Мост между SAPI 5 и синтезатором Newfon: голос становится доступен любой
программе Windows, которая умеет читать текст через SAPI — экранным чтецам
(NVDA, JAWS), читалкам книг (Балаболка, Говорилка) и всему остальному.

В комплекте идёт конфигуратор: частота синтеза, интерполяция, ускорение, паузы,
произношение букв, сочетаний и символов, пользовательский словарь ударений.

## Что внутри

| Каталог | Что это |
| --- | --- |
| `src/sapi` | сам мост: реализация `ISpTTSEngine`, подготовка текста, звук |
| `src/config` | чтение `prefs.ini`, словаря и замен символов |
| `src/rulex` | обёртка над словарём ударений RuLex и его экспорт в `rulex.dll` |
| `configurer` | конфигуратор на PureBasic |
| `config` | значения по умолчанию: `prefs.ini`, `symbols.ini`, `config.spec` |
| `docs` | справка, которую открывает конфигуратор по F1 |
| `installer` | скрипт Inno Setup |
| `cmake` | вспомогательные модули сборки |
| `tests` | интеграционный тест движка и проверка конфигуратора |
| `Newfon_core`, `external` | подмодули: ядро Newfon, RuLex, LMDB, PCRE2, libsamplerate |

Настройки пользователя лежат в `%APPDATA%\NewfonSAPI`: `prefs.ini` и словарь
`ru_dict.dic`. Движок и конфигуратор читают и пишут только туда.

## Сборка

Нужны:

- [LLVM-MinGW](https://github.com/mstorsjo/llvm-mingw) — в `PATH` или в переменной `LLVM_MINGW`;
- [CMake](https://cmake.org/) 3.24 или новее;
- [PureBasic](https://www.purebasic.com/) — для конфигуратора;
- [Inno Setup 6](https://jrsoftware.org/isinfo.php) — для установщика;
- Python 3 — для проверки конфигуратора.

```bash
git clone --recursive https://github.com/nikkov199525/newfon_sapi
```

Если репозиторий уже склонирован без подмодулей:

```bash
git submodule update --init --recursive
```

Дальше одна команда собирает обе разрядности, прогоняет тесты и делает
установщик в `build\x64\installer`:

```bash
build_release.cmd
```

Имя команды, порядок сборки и каталог установщика сохранены. Батник вызывает
единый сценарий CMake; его можно запустить напрямую из любого каталога,
указав путь к сценарию:

```bash
cmake -P cmake/Release.cmake
```

Сценарий выбирает Release, включает конфигуратор и тесты даже для существующих
деревьев сборки и останавливается при первой ошибке. Проверка конфигуратора
входит в CTest и находит Python через CMake — команда `python` в `PATH`
больше не обязательна.

Отдельная разрядность собирается обычным образом:

```bash
cmake -S . -B build/x64 -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-x64.cmake
cmake --build build/x64 --parallel
ctest --test-dir build/x64 --output-on-failure
```

Цель `installer` собирает пакет из обоих деревьев сборки, поэтому дерево `x86`
должно быть собрано раньше. Если конфигуратор не нужен, сборку можно отключить
через `-DNEWFON_BUILD_CONFIGURATOR=OFF`.

## Установка

Установщик кладёт обе разрядности движка (`x86` и `x64`) и регистрирует их, так
что голос видят и 32-, и 64-битные программы. База ударений `rulex.db` одна на
обе. Если во время установки экранный чтец держит библиотеку загруженной, она
переименовывается, а новая встаёт сразу: достаточно перезапустить чтец, без
перезагрузки.

Пользователям JAWS нужно дописать секцию в `sapi5x.ini` — как именно, написано в
справке, раздел «Пользователям JAWS For Windows».
